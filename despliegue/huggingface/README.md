# Voces · Diarización de hablantes

Sube o graba un audio para estimar cuántas voces hay, cuándo habla cada una y
cuánto participa. Usa ERes2Net (sherpa-onnx), WebRTC VAD y agrupamiento
jerárquico.

Este Space se publica automáticamente desde GitHub
(`.github/workflows/huggingface.yml`): los cambios hechos aquí se sobrescriben.
